# Weather Project

A student project with a static weather website and a visual preview of the companion Flutter app.

## Files

- `index.html`, `about.html`, and `contact.html` — website pages.
- `style.css`, `aboutme.css`, and `contactme.css` — website styles.
- `script.js` — weather API requests and page behavior.
- `weather-app-preview.png` — visual preview of the Flutter app screens.


## Run the website locally

Open `index.html` in a browser. Weather requests require an OpenWeatherMap API key. For local testing, replace `YOUR_OPENWEATHERMAP_API_KEY` in `script.js` with your own key. Do not commit a real key. A browser-based public deployment exposes any key included in its JavaScript; use a backend proxy for a public live demo.

## Flutter app source

The supplied archive included a preview image and syntax-highlighted HTML exports of a few Dart files, but not the complete Flutter source project (including its `lib/` directory and app entry point). The preview is included here; add the original complete Flutter project separately if you want this repository to contain a runnable Flutter app.
